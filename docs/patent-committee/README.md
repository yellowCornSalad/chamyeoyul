# 특허심의위원회 설치·운영(안) — 대표이사 보고 자료

사내 표준 양식(엔키화이트햇 회사소개서, 2026 ver.)의 서식 체계를 적용한 보고용 덱입니다.

## 산출물
- `특허심의위원회_설치운영안_보고.pptx` — 13장 (16:9)
- `build_deck.js` — 덱 생성 스크립트 (`NODE_PATH=<pptxgenjs 경로> node build_deck.js`)
- `assets/bg_cover.jpg`, `assets/bg_contents.jpg` — 회사소개서 표지·목차의 배경 아트에서 텍스트를 제거해 재사용한 이미지

| 표·박스 | 파란 헤더(`#1C67C7`) + 흰 본문 박스(테두리 `#C9D8EC`), 표 헤더 파란 채움 |

## 원문 보고 대비 수정 사항
- 「발명진흥법」 제13조의 정식 조문 제목은 **"승계 여부의 통지"** 입니다.
  (1차 보고문의 "직무발명의 권리승계"는 조문 제목이 아니므로 정정 반영)
- 승계 여부 통지 기한 4개월의 근거를 **발명진흥법 시행령 제7조**로 명시.
- 출원유보보상금·해외출원보상금·처분/실시보상금은 사내에 제도가 없어 보상 체계에서 제외했고,
  이에 맞춰 법적 근거에서도 제16조(출원 유보 시의 보상) 행을 삭제했습니다. 보상은 출원·등록 2회로 운영합니다.
